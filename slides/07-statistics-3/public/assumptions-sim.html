When assumptions break

The Z test promises Type I rate $\alpha$ only if the data matches its assumptions. We compute $Z = \sqrt{n}\,\bar X$, with the test assuming iid $\mathcal{N}(0, 1)$. Switch the source to $t(3)$, which has heavy tails and variance $3$ instead of $1$. The test does not know this and still uses $\sigma = 1$, so the empirical Type I rate climbs above $\alpha$.
