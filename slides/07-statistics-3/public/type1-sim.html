Type I error under $H_0$

We simulate the one-sample test of $H_0: p = 0.5$ on Bernoulli data. Each draw produces a sample of size $n$ from $\text{Bernoulli}(0.5)$, so $H_0$ is true by construction. We compute the standardised statistic $Z = (\bar X - 0.5) / (0.5/\sqrt{n})$, which under $H_0$ is approximately $\mathcal{N}(0,1)$ by CLT. The shaded region is the rejection region: where the test would reject $H_0$. Because $H_0$ is true here, every rejection is a Type I error. The empirical false-positive rate converges to $\alpha$.
